# Audio recordings: credits and licence

Every recording in this folder is **CC0 1.0 (public domain dedication)**, from [Freesound](https://freesound.org).
No attribution is legally required; the authors are credited here anyway. The licence of each source was
verified on its Freesound page when the Deadfall asset set was built (Freesound HQ previews, CC0 only).

The files were prepared for Deadfall (filtered, sliced into multi-take sprites, loops made seamless) and then
re-encoded for this game: ambience beds trimmed to 40-60 s with an equal-power seamless loop point and encoded as
32 kHz Ogg Vorbis, one-shots re-encoded as mono Ogg Vorbis. Slice tables live in `../samples.js`.

Licence: https://creativecommons.org/publicdomain/zero/1.0/
